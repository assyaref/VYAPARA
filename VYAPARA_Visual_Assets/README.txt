VYAPARA — Visual Brand Assets
================================

Folders:
00_Previews/             Original overview and asset-sheet previews
01_Logo/                 Logo lockups and monochrome concepts
02_App_Icons/            Windows and platform icon concepts
03_Module_Icons/         Individual module icon tiles
04_Brand_Colors/         Individual brand color swatches
05_Desktop_Branding/     Splash screen and login screen concepts
06_UI_Mockups/           Desktop, POS, mobile and feature mockups

Transparency notes:
- PNG files have been separated into individual files.
- App icon tiles have transparent pixels outside their rounded-square shape.
- Other logo lockups and full UI mockups retain their designed backgrounds.
  A full UI screenshot is not meaningfully transparent because its interface
  surface is part of the image.
- These are visual concept crops from generated brand sheets/mockups, not
  editable vector masters. For production, recreate the logo as SVG and
  implement the UI directly in the application.
