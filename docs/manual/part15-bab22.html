Bab 22 — Loyalty Points & Piutang Pelanggan

22.1 Loyalty Points — cara kerja

  • Setiap pelanggan memiliki saldo poin yang bertambah otomatis pada setiap transaksi selesai.
  • Default: Rp 10.000 = 1 poin (dapat diubah di Pengaturan dengan kunci loyalty_earn_amount).
  • Saldo poin tidak hangus; tidak ada kedaluwarsa.

22.2 Mendapatkan poin di kasir

  1. Di layar kasir, bagian bawah → Pelanggan (opsional).
  2. Ketik nama/telepon/kode — daftar pelanggan muncul; klik salah satu.
  3. Pelanggan terpilih menampilkan: nama, saldo piutang, dan poin di kanan bawah picker.
  4. Checkout seperti biasa — poin otomatis ditambahkan berdasarkan total (setelah diskon, sebelum/sesudah PPN? → dihitung dari total akhir).
  5. Lihat laporan: menu Pelanggan → detail pelanggan → jumlah poin.

22.3 Menggunakan poin sebagai diskon

  1. Pilih pelanggan di kasir — centang “Pakai N poin (− Rp X)”.
  2. Diskon poin diterapkan sebelum PPN dihitung.
  3. Aktif hanya jika saldo poin > 0.

22.4 Metode pembayaran Kredit (piutang)

  1. Pilih pelanggan → tombol pembayaran berubah menjadi empat pilihan + Kredit.
  2. Pilih Kredit → Klik Bayar (F10) — transaksi tercatat sebagai penjualan kredit; saldo piutang pelanggan bertambah sebesar total.
  3. Piutang muncul di menu Pelanggan → badge piutang merah.
  4. Pelanggan dapat membayar sebagian/lunas di menu Pelanggan → tombol Terima Pembayaran Piutang.

22.5 Laporan Piutang (AR Aging)

Menu Laporan & Analisis → tab Piutang — tabel semua pelanggan dengan saldo > 0:

22.6 Contoh alur piutang

  1. Budi membeli total Rp 80.000 secara Kredit.
  2. Menu Pelanggan → Budi → piutang Rp 80.000.
  3. Satu bulan kemudian Budi membayar Rp 50.000 (Pelanggan → Terima Pembayaran).
  4. Sisa piutang = Rp 30.000 — aging berubah menjadi 31-60 sejak transaksi itu.
Tip pasar ATK: pelanggan langganan sering “titip bayar” — gunakan piutang untuk mencatat hutang, bukan “uang masuk/kasir”.

22.7 Memastikan poin & piutang sinkron antar perangkat

Poin dan piutang adalah bagian dari data pelanggan — disinkronkan via Offline Sync seperti semua data lain (lihat Bab 10). Transaksi penjualan kredit dan pembayaran piutang keduanya menghasilkan event yang dikirim ke server.
