# Design System — VYAPARA

Brand: VYAPARA — Business Management. Makna terinspirasi dari Sanskerta
`Vyāpāra` (व्यापार), perdagangan/aktivitas usaha. Tagline: **Kelola Usaha
Lebih Mudah, Terintegrasi, dan Bertumbuh.** English: **Manage Your
Business Smarter.**

## Colors

| Token      | Hex       | Usage          |
|------------|-----------|----------------|
| Navy       | `#0D47A1` | Primary brand  |
| Blue       | `#1976D2` | Actions        |
| Orange     | `#FF8F00` | Accent         |
| Light blue | `#E3F2FD` | Soft surfaces  |
| Surface    | `#F5F7FA` | App background |
| Text       | `#172033` | Main text      |
| Secondary  | `#64748B` | Secondary text |
| Border     | `#E2E8F0` | Dividers       |
| Success    | `#15803D` | Success        |
| Warning    | `#D97706` | Warning        |
| Danger     | `#DC2626` | Error          |

Font Inter or system sans-serif. Use tabular numerals for amounts.

## Desktop

Target minimum 1366x768. Sidebar navigation, header with
user/connection/sync status, readable tables, clear page hierarchy,
keyboard-friendly POS, no horizontal overflow in checkout.

## Unified POS

Item/service selector plus one cart. Customer/order metadata visible.
Total/payment summary prominent. Each item can open specification and
fulfillment detail.

## Status

Use text plus color: Offline/Online; Pending/Syncing/Synced/Error;
Unpaid/Partially Paid/Paid; Pending/In Progress/Ready/Completed.

## Owner web

Responsive desktop/tablet/mobile. Show reporting period, timezone, last
updated, pending sync, and freshness warning.

## Assets

Inspect actual files in `VYAPARA_Visual_Assets/`. Verify dimensions and
transparency. Do not treat cropped mockup PNG as vector master. Do not
invent asset paths.
